# 유입 DB 매출 단계 요약

2026-09-18 로컬 구현·검증 완료. 사용자 후속 요청으로 프런트 단독 배포 진행. 실제 배포·자산 검증 결과는 로컬 운영 원장 `pocket-kpi-deploy/PROJECT_STATE.md`에 기록한다.

- 위치: 통합 성과 체크 → 유입 DB → 일별 그래프 바로 아래.
- 원천: 이미 로드된 리드의 `crmSheet.annualSalesRaw`, `crmQuality.values.annua_sales_structured`, `crmSheet.annualSales`, `crmQuality.values.annua_sales` 순서의 첫 유효 응답. 외부 API 추가 호출·DB 쓰기 없음.
- 세 카드: 매출없음/예비/서비스 제작단계, 매출 1억 이상, 매출 10억 이상. 10억 이상 응답은 두 번째 카드에 중복 포함하지 않는다.
- `발생_매출_3억_이상`처럼 하한만 명시된 응답은 하한 기준 1억 카드로 표시한다. 실제 매출이 10억 미만임을 확정한 분류가 아니다.
- `5~20억`, `5억 미만`, 1억 미만 금액, 금액 없는 매출 발생 및 그 밖의 모호한 값은 확인 필요. 빈 응답은 미입력이며 매출없음과 구분한다. 통화 메모 추론·TM 점수·계약액으로 대체하지 않는다.
- 그래프의 선택 월/신규·기존/기간 필터와 동일한 `dailyCounts.entries`를 사용하되 월 요약에는 주말을 포함한다. 일간 보기에서도 그래프와 같이 해당 월 전체 기준, 현재 월은 오늘까지다. 기간 선택은 월과 선택 범위의 교집합이다.
- 선택된 그래프 날짜의 각 분류 건수를 카드 아래 별도 표시한다. 기존 그래프는 평일만 표시하며 바꾸지 않는다.
- 세 카드+미입력+확인 필요 합계는 대상 리드 수와 일치한다. 업체명으로 임의 병합하지 않고 기존 유입 건수의 행 단위를 유지한다.
- 검증: 신규 6개 테스트, 전체 144개 테스트, 프로덕션 빌드 검사 통과. 합성 데이터로 경계값·응답 우선순위·주말·신규/기존·날짜 필터·렌더링·HTML 이스케이프·비변경성 확인. 운영 고객 데이터 재조회나 브라우저 시각 검사는 하지 않았다.
- 최초에는 보안 전환 전 공개 배포를 보류했으나, 사용자의 명시적인 후속 배포 요청으로 이 화면 기능만 배포한다. 별도 직원 인증 준비 코드는 포함하지 않는다. 이번 변경에는 신규 API·인증 변경·고객 데이터 정적 포함이 없으며, 기존 인증의 보안 문제가 해결된 것은 아니다.
- 원복은 새 컴포넌트 import와 호출 제거로 가능하며 데이터 마이그레이션은 없다.

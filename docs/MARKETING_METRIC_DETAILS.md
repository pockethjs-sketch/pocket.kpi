# 마케팅 지표 상세·문의 원천 구분

## 2026-09-18 계약당 비용 상세

- 계약당 비용 클릭 시 일반 업체 목록 대신 기존 계약 상세 목록을 사용한다. 선택 기간/신규·기존 필터의 계산 대상 계약 전체(행수 제한 없음), 업체별 계약금액·유형·담당·빌드업·계약일·입금·미수·결제 회차와 합계를 표시한다. 업체 클릭 상세 연결 유지. 신규/기존을 함께 보려면 전체 필터를 사용한다.
- 운영 읽기 확인: 펩스데이 신규 2,500만원은 계약일 2026-09-07, 프리미팅일 2026-08-14이므로 9월 계약/8월 프리미팅 기업에 각각 포함된다. 별도 기존 1,800만원 기록은 계약일 2026-07-08, 프리미팅 완료일 2026-07-29이다. 저장 누락이 아닌 날짜 기준 차이이며 동일 이름만으로 병합/날짜 변경하지 않았다.
- Supabase crm 읽기 API HTTP 200, 843개 활성 리드 중 해당 두 기록을 확인했다. 프런트 상세 표시만 변경하고 업체/금액/일정/필터 판정/DB/시트는 변경하지 않는다.

## 2026-09-18 건수 증감·건당 비용 전월 비교

- 절대값 3개는 `126건 +13건 / 500` 순서로 표시한다. 증감은 현재−전일 비교값의 건수이며 퍼센트가 아니다. 0→3도 `+3건`, 같으면 `0건`. 실제 수치와 증감을 한 묶음으로 두고 목표는 뒤에 별도 표시한다.
- 리드당/프리미팅당/계약당 비용의 증감만 전일에서 전월로 변경. 이번 달은 전월 1일~동일 일자(월말 초과 시 전월 말일)까지, 완료된 월은 전월 전체와 비교한다. 선택 월의 마지막 날에는 월 전체끼리 비교한다. 연/일/전체/직접 기간은 기존 건당 비용 본값을 유지하고 월 비교는 불가라고 설명한다.
- 전월 분모는 같은 신규/기존 필터와 기존 유입일/프리미팅 기업/계약일 조건으로 재집계한다. 완료된 월 비교는 저장된 전월 광고비 합계, 부분월 비교는 META/NAVER/GOOGLE 모든 날짜가 존재하는 일별 광고비만 사용한다. 결측·중복·음수는 비교 불가이며 월 합계 임의 일할 계산은 하지 않는다. 미래 일정 포함으로 현재 카드 수와 오늘까지 수가 다른 경우도 비교하지 않는다.
- 비용 증감은 계속 상대 %이며 `전월` 표시와 전후 날짜/금액 설명을 제공한다. ROAS·전환율·하단 금액의 전일 대비는 유지. 주말은 비용/건수 합계에 포함되며 그래프만 숨긴다. 저장/동기화/DB/시트 변경 없음.

## 2026-09-18 일별 그래프 → 평일 선 그래프

- 통합 성과의 유입 DB·프리미팅·계약 상세를 막대에서 선 그래프로 변경. 토요일/일요일을 표시 단계에서 제외하고 금요일→월요일을 연결한다. 공휴일은 별도로 제외하지 않는다.
- 0건 평일을 유지하고 점/날짜 클릭·Enter/Space로 해당 날짜를 선택한다. 방문 완료는 보라 실선, 미확인은 회색 점선이며 유입은 파랑, 계약은 초록이다.
- 그래프 요약은 명시적으로 평일 합계다. 원본 활동·월간 KPI·전일 대비 계산은 주말 포함 그대로 유지한다. 오늘까지 표시·신규/기존 필터·날짜별 업체/계약 상세 연결도 유지한다. DB·수집·저장 변경 없음.

## 2026-09-18 통합 성과 전일 대비

- 유입/프리미팅/계약 수, 전환율, 건당 비용, 총 광고비, 총 계약액, ROAS 옆에 증감률을 표시한다. `(현재−비교값)÷비교값×100`, 소수 1자리이며 ROAS/전환율도 %p가 아닌 상대 증감률이다. 비용 감소는 개선 색상, 수/계약액/ROAS 증가는 개선 색상이다. 총 광고비 색상은 비용 증감일 뿐 효율 판정이 아니다.
- 월/연/전체/기간은 시작일을 유지한 누적값과 마지막 날짜 전일까지 누적을 비교한다. 현재 기간은 오늘을 상한으로 하고 과거 월은 월말 vs 월말 전일이다. 일 선택은 해당 일 vs 전일이다. 화면에 비교 날짜를 명시하고 신규/기존 필터를 동일 적용한다.
- 현재 저장된 유입일/프리미팅 기업 판정/계약일로 재계산한다. **어제 화면의 스냅샷이 아니며 과거 수정·삭제·후행 동기화의 발생 시점은 복원하지 않는다.** 기존 월 카드 합계를 바꾸지 않으며 미래 일정 때문에 날짜 상한 집계와 다르면 해당 증감률은 비교 불가다.
- 광고비는 기존 월/연 집행액을 유지한다. META/NAVER/GOOGLE 일별 합계가 표시 광고비와 1원 이내로 일치하고 세 공급자 일별값이 비교일(D-1) 이상일 때만 전일 분모를 계산한다. 광고비는 하루 1회 수집되므로 오늘 광고비가 없으면 저장된 D-1까지 금액으로 현재/전일을 계산한다. 월 합계를 일수로 배분하지 않는다.
- 비교값 0→양수는 `신규 발생`, 0→0은 `— 0%`, 누락/오래된 광고비/분모0 등은 `비교 불가`. 마우스오버와 접근성 설명에 전후 숫자·계산식·제약을 표시한다.
- 프런트 계산/표시만 변경. DB·광고 수집·CRM 동기화·Apps Script·백업·사용자 저장값은 변경하지 않는다.

## 2026-09-18 프리미팅·계약 일별 상세

- 통합 성과 체크의 유입 DB/프리미팅 수/계약 수를 누르면 선택 월의 일별 그래프를 표시한다. 날짜 버튼은 0건 날짜도 선택 가능하며 신규/기존 필터를 유지한다. 현재 월은 오늘까지 표시한다.
- 프리미팅은 CRM `type=1` 일정의 한국시간 미팅 날짜로 집계한다. `checked=1`만 방문 완료, 나머지는 방문 미확인이다. 같은 업체의 같은 날짜는 한 번, 다른 날짜는 각각 집계한다. 현재 계약/드랍 상태가 과거 일정의 참석 여부를 바꾸지 않는다.
- CRM 일정이 없는 수동/구형 업체는 저장된 `premeetingDoneAt`, 없으면 `premeetingAt/bookedAt`을 사용한다. 완료일 또는 기존 프리미팅 완료/견적/계약 단계에 저장된 미팅일은 완료로 집계한다. 유입일이나 계약일로 미팅일을 추정하지 않는다.
- 프리미팅 월간 카드는 기존 프리미팅 기업 수다. 일별 방문 그래프에는 반복 방문과 방문 후 드랍된 업체의 과거 기록도 포함하므로 월간 고유 업체 수와 같지 않을 수 있다. 그래프에 이 차이를 명시한다.
- 계약은 현재 `계약 완료` 업체의 `contractAt` 기준으로 행당 1건이다. 선택 날짜 아래에 신규/기존·계약금액·입금·미수·결제 회차 상세를 유지한다. 프리미팅은 선택 날짜의 업체·담당자·방문 여부를 보여주며 업체 상세로 연결한다.
- 9/18 운영 읽기 대조: 9월 오늘까지 유입 126건, 프리미팅 일정 46건(완료 29/미확인 17), 계약 14건. 예: 9/17 방문 완료 2·미확인 1, 9/18 완료 0·미확인 7. 저장된 방문 체크 상태 기준이며 아직 동기화되지 않은 방문은 포함할 수 없다. 저장/수집 변경 없음.

## 2026-09-18 마케팅 총괄·통합 성과 기준 통일

- 통합 성과 체크와 마케팅 총괄의 기본 `ROAS`는 동일하게 **선택 기간에 계약일이 있는 계약 완료 업체의 계약액 ÷ 같은 기간 전체 광고비 ×100**이다. 계약액은 `contractAmount`를 우선하고 없으면 결제 회차의 예정액 합계를 사용한다. 입금 여부는 기본 ROAS에 영향이 없다.
- 마케팅 총괄 ROAS 그래프와 월별 표는 신규·기존을 별도 두 줄로 표시한다. 두 값 모두 같은 전체 광고비를 분모로 사용하므로 반올림 전에는 둘을 더하면 전체 ROAS가 된다. 정수 반올림된 표시값의 합은 전체값과 1%p 다를 수 있다. 기존 고객의 광고비를 별도 귀속했다는 뜻은 아니다. 계약이 없는 유형은 0%, 광고비가 없으면 `-`다.
- 마케팅 총괄의 `프리미팅` 월별 건수는 해당 월 프리미팅 기업 수이며 통합 성과 체크의 프리미팅 단계와 동일한 `isPremeetingCompanyInRange` 기준이다. 기존 `유입 DB 코호트의 이후 방문 완료 수`와 구분한다.
- 통합 성과 체크의 `유입 DB` 절대값 상세는 업체 목록 대신 선택 월의 `createdAt` 날짜별 선 그래프다. 현재 월은 오늘까지, 과거 월은 말일까지 0건 평일도 표시하며 토·일은 숨긴다. `전체/신규/기존` 필터를 따른다. 연/전체/직접 기간에서는 조회 월을 고를 수 있다.
- 운영 2026-09-18 읽기 전용 대조: 9월 유입 DB 126건, 전체 광고비 11,052,167.77원, 계약액 신규 73,217,400원·기존 40,480,000원 → 신규 ROAS 662%·기존 366%·전체 1,029%(각각 반올림). 이 값은 고정하지 않고 운영 데이터에서 계속 재계산한다. 프런트 표시만 변경했으며 Supabase/Apps Script/시트/수집 일정은 변경하지 않았다.
- 아래 META/NAVER+GOOGLE **매체 상세**의 기존 `ROAS`는 여전히 `유입 코호트 누적 입금 ÷ 매체 광고비`여서 기본 계약액 ROAS와 다른 분석 지표다. 같은 이름만으로 비교하면 안 된다.

- META / NAVER+GOOGLE 상단 6개 카드(광고비, 유입 DB, CPL, DB→프리미팅, 계약, ROAS)를 누르면 **해당 카드가 집계한 월과 실제 사용된 값**을 표시한다. 월별 광고비·업체별 유입일/채널/프리/계약액/누적 입금을 함께 보여준다. 카드와 상세는 같은 `summaryRows`를 사용한다.

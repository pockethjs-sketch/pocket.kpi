# 데일리 회의 기록

## 화면

- 위치: `통합 성과 체크` 하단
- 제거된 화면: 최근 진행 중인 마케팅 액션, 마케팅 Log, 마케팅 기록 등록
- 새 화면: 날짜·시간·참석자·안건·결정사항·후속 액션을 한 기록으로 저장하는 데일리 회의 피드
- 정렬: 오래된 기록이 위, 최신 기록이 아래다. 저장 직후 목록의 아래쪽으로 이동한다.

## 저장

- 운영 정본: 기존 Supabase 호환 문서의 `marketingLogs` 컬렉션
- 구분값: 새 회의 기록은 `kind: "meeting"`
- 기존 `kind: "action"`, `kind: "log"` 자료는 삭제하지 않고 화면에서만 숨긴다.
- 기존 V3 patch 저장, 브라우저 미반영 저널, 리비전 충돌 재병합, Sheets 비동기 백업을 그대로 사용한다.
- 별도 API·DB 테이블·Apps Script 배포는 필요하지 않다.

## 필수 입력과 호환

- 안건은 필수다.
- 결정사항 또는 후속 액션 중 하나 이상이 있어야 저장한다.
- 구형 `마케팅_로그` 백업 원장에서도 내용을 잃지 않도록 안건은 `action`, 결정사항과 후속 액션은 `note`에도 함께 기록한다.

## 비영향 범위

- 통합 성과 KPI 계산, CRM, 광고 수집, 계약·입금, 권한, 동기화 일정은 변경하지 않는다.
- 기존 마케팅 로그 데이터는 물리 삭제하지 않는다.

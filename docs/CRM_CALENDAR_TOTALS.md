# CRM 프리미팅 집계 정본 (2026-10-14)

- 기존 일별 그래프만 CRM 원본 일정으로 전환하고 상단 합계는 업체별 중복 제거 집계를 남겨 둔 회귀를 수정한다.
- 통합성과 카드·일별·상세 목록·증감·비용·엑셀 및 마케팅 총괄의 카드·월별 추이·채널 표는 `calendarPeriodEntries`/`dailyStageActivity`의 같은 CRM 일정 행을 사용한다.
- 집계: 조직 범위의 최신 원본 일정, type=1, 일정 ID별 중복 제거, KST 미팅일, 선택 기간 및 오늘까지. 방문 체크/현재 영업 상태는 숫자를 제외하는 조건이 아니다. 동일 업체의 별도 일정은 각각 집계한다.
- 그래프의 기존 주말 숨김은 유지하되 주말 포함 합계를 별도로 명시한다. 하루 필터는 카드와 프리미팅 그래프 모두 같은 날짜만 집계한다. 업체 미연결 일정도 전체에 포함하고 신규/기존 미확인은 미분류로 유지한다.
- 비율은 일정 건수 대비 비율이다. 고유 업체의 코호트 전환율이 아님을 설명한다. 계약액·실입금·ROAS 및 유입/결제기업의 기존 기준은 바꾸지 않는다.
- 달력 조회 실패/미완료는 카드·월별·채널 표에서 0건이 아니라 미확인으로 표시한다. 원본 고객 자료/인증정보를 테스트 fixture나 로그에 출력하지 않는다.
- 검증: 운영 원본의 메타데이터 전용 SQL 집계에서 10월14일까지29건, 10월8일3건·14일3건. 합성 21업체/29일정으로 실제 통합성과 계산과 마케팅 총괄 SSR, 일별 합, 상세 행 수 일치. KST 경계·주말·미연결·중복·미래 제외·조회 실패 회귀 포함. 290개 테스트, 보안/빌드 검사 통과, npm audit 0건.
- 이번 변경은 프런트 집계만이다. DB/API/권한/수집 실행/트리거 변경 없음. 실직원 인증 브라우저 화면은 별도 미검증이며 공개 자산 배포 검증과 혼동하지 않는다.

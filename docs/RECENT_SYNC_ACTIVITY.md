# 최근 동기화 탭

2026-09-15. `프리미팅 기업 → 기업 목록 / 최근 동기화` 내부 탭. 별도 메뉴 권한은 만들지 않고 기존 프리미팅 기업 접근 권한을 그대로 따른다.

## 표시 기준

- Supabase `kpi-domain-api?action=bootstrap`의 `documents.contractStatusLogs`를 읽기 전용으로 조회한다. 운영 저장 위치는 `app_documents`; Sheets의 `데이터_계약현황로그`는 비동기 백업이다.
- CRM 동기화 및 외부 시트 자동 반영으로 **실제로 추가·변경된 업체 기록**만 표시한다. 일정 건수나 단순 조회 성공 횟수가 아니다.
- 허용 action: `CRM 동기화`, `CRM 자동 동기화`, `CRM 수동 동기화`, `외부 시트 자동 반영`. 직접 추가·CRM 링크 수동 입력·외부 시트 수동 생성/제외·실패·보류·무변경 확인은 포함하지 않는다.
- ‘자동 반영’은 시스템이 값을 반영했다는 뜻이며, 예약 실행인지 사람이 동기화 버튼을 눌렀는지는 기존 로그가 구별하지 않는다. 이 구분을 추정하여 표시하지 않는다.
- 기본 최근 7일(한국시간, 오늘 포함), 오늘/최근 30일/전체 기록 선택. 미팅일이나 상단 선택 월이 아닌 로그 `at` 시각 기준이다. 날짜만 있거나 시각이 없으면 전체 기록에서 `기록 시각 없음`으로 표시한다.
- 출처, 기업 생성/정보 수정/구분 미기록, 업체명·내용 검색. 동일 로그 ID 중복은 숨기지만 한 업체의 서로 다른 변경은 각각 유지한다. 업체 수와 반영 건수를 별도 표시한다.
- `meta.previousStatus=미등록`만 기업 생성으로 확정하고, 계약 시트 자동 반영이나 기록된 기존 상태가 있는 CRM 변경은 정보 수정으로 표시한다. 나머지 옛 기록은 구분 미기록이다.
- 시트의 `meta.before/after`에서 바뀐 계약액·계약일·상태·빌드업·메모를 펼쳐볼 수 있다. CRM은 저장된 전후 상태와 설명만 표시한다. 현재 업체 값으로 과거 전후값을 만들어내지 않는다.
- 삭제·보관·현재 목록에 없는 업체도 로그는 보존하되 상세 연결은 비활성화한다. 이름이 변경되었으면 당시 이름과 현재 이름을 구분한다.

## 부작용 방지

- 탭을 열거나 `내역 새로고침`을 누르면 저장된 로그만 읽는다. CRM/시트 원천 수집, 데이터 저장, 일일 스케줄 변경을 실행하지 않는다.
- 원격 저장이 확인되지 않은 브라우저 임시 로그를 성공 기록으로 보여주지 않는다. 최초 읽기 실패와 기록 0건을 구분한다. 재조회 실패 시 마지막 정상 목록을 유지한다.
- 새 동기화 성공 상태가 도착하면 열린 탭의 로그를 다시 조회한다. 화면 종료·빠른 재조회 시 이전 요청 결과가 최신 결과를 덮지 않도록 요청 번호로 보호한다.
- 기본 50건씩 표시하고 더 보기를 제공한다. 업체 리스트와 집계·금액·입금·백업·Apps Script v58·오전 9시 작업은 변경하지 않는다.

## 구현·검증

- `src/RecentSyncActivity.jsx`: 독립 읽기 전용 UI.
- `src/data/syncActivity.mjs`: 로그 분류·중복 제거·KST 기간·전후값 표시 규칙.
- `tests/sync-activity.test.mjs`: 수동/실패 제외, 반복 ID, 다중 변경, 날짜 경계, 원본 불변, 알 수 없는 과거 시각, 읽기 전용 경로.
- 최초 실제 조회에서 총 활동 로그 78건 중 자동 반영 65건(CRM 53/시트 12) 확인. 이는 전체 이력이며 기본 최근 7일 결과와 다를 수 있다.
- 실제 모델 대조: 최근 7일 26개 업체·51건, 오늘 14건. 원격 리비전 `20260915080053524-54mg` 유지. 조회 시점 기준 숫자로 이후 자동 반영에 따라 증가할 수 있다.
- 테스트 90개, 프로덕션 빌드, npm audit(취약점 0) 통과. 격리 브라우저에서 탭 전환·출처/기간 필터·0원→550만원 전후값·상세 열기·삭제 업체 연결 차단·읽기 실패 후 정상 내역 유지·데스크톱/모바일 확인.
- 과거 로그의 누락된 시각·필드를 역산하거나 로그를 새로 생성하지 않는다. 이번 변경은 웹만 배포하며 운영 데이터 마이그레이션이 없다.
